# Receita Alheia App
Aplicação em Streamlit para geração de ficheiros Receita Alheia.

## Dashboard Financeiro ULSLA — execução local

A plataforma financeira local está na pasta [ULSLA_Dashboard](ULSLA_Dashboard/README.md). Inclui Dashboard, Contabilidade Analítica, Importação XML, Produção de Mapas, Contratualização e Verificação de Dados.

No Windows, abrir `ULSLA_Dashboard/INSTALAR_LOCAL.bat` e depois `ULSLA_Dashboard/INICIAR_LOCAL.bat`. Os dados financeiros e cadastros permanecem no computador local.
